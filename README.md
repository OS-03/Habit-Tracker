## Project Overview

This project is a **Habit Tracker** application designed to help users monitor and improve their daily habits. It provides an intuitive interface for tracking habits, setting goals, and visualizing progress over time.

### Features

- **Add and Manage Habits**: Users can create, update, and delete habits.
- **Progress Tracking**: Visualize daily, weekly, and monthly progress.
- **Reminders**: Set reminders to stay consistent with habits.
- **Responsive Design**: Fully optimized for both desktop and mobile devices.
- **Dark Mode**: Toggle between light and dark themes for better usability.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or

```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Project Structure

The project follows a modular structure for better scalability and maintainability:

- `app/`: Contains the main application logic and pages.
- `components/`: Reusable UI components.
- `styles/`: Global and component-specific styles.
- `utils/`: Helper functions and utilities.
- `public/`: Static assets like images and icons.
